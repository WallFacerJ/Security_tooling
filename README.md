
# Python Security Labs

A collection of small Python security projects and experiments built to practice networking, security concepts, and automation.

These scripts are intentionally lightweight and are primarily used for hands-on learning and experimentation.

## Projects

### Port Scanner

A basic TCP port scanner built with Python's `socket` library.

The scanner:

- Accepts a target IP address
- Scans TCP ports for connectivity
- Identifies several common services
- Reports discovered open ports

```bash
python port_scanner.py
````

### Password Attack Demo

A small educational demonstration of common password-guessing concepts.

Includes examples of:

* Wordlist-based password guessing
* Brute-force-style attempts
* Attempt counting
* Account lockout behavior

```bash
python password_attack_demo.py
```
